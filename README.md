# EventPulse API

A robust RESTful API built for managing events, built with Node.js, Express, and MongoDB.

## Tech Stack
* **Runtime:** Node.js
* **Framework:** Express
* **Database:** MongoDB / Mongoose
* **Testing:** Jest, Supertest
